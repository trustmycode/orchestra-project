## Описание

Заменить стандартные HTML-инпуты (`<input type="file">`) на современный компонент Dropzone, позволяющий перетаскивать файлы мышкой.

## Ключевые шаги

1.  **Зависимости:** Установить `npm install react-dropzone`.

2.  **Компонент `FileDropzone`:**

    *   Создать `src/components/ui/file-dropzone.tsx`.

    *   Реализовать визуальные состояния: "Ожидание", "Файл над зоной" (DragOver), "Файл выбран".

    *   Использовать иконку `UploadCloud` и пунктирную рамку.

    *   Добавить кнопку "Удалить" (крестик) для сброса выбранного файла.

3.  **Интеграция:**

    *   Обновить `ImportView.tsx`, заменив инпуты для BPMN, PlantUML и Specs на новый компонент.

## Критерии приемки

- [ ] Пользователь может перетащить файл из ОС в зону загрузки.

- [ ] При наведении файла зона подсвечивается.

- [ ] После выбора отображается имя файла.
