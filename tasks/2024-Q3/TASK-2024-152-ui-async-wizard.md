## Описание

Адаптировать UI для работы с новым асинхронным флоу.

## Ключевые шаги

1.  **AiWizard:**

    *   Добавить выпадающий список `Environment` на последнем шаге.

    *   Переключить вызов на `/async` эндпоинт.

    *   Реализовать логику "Fire and Forget": закрывать окно сразу после успешного старта задачи.

2.  **ScenarioSuiteListView:**

    *   Отображать сьюты со статусом `GENERATING` с прогресс-баром (компонент `Progress`).

    *   Отображать сьюты со статусом `FAILED` с красным бейджем и тултипом ошибки.

    *   Кнопка "Delete" должна быть активна для `FAILED` сьютов (ручная очистка).

    *   Реализовать локальный поллинг статуса (или использовать глобальный из следующей задачи).

## Критерии приемки

-   Пользователь выбирает Environment в визарде.

-   После нажатия Generate визард закрывается, в списке появляется новый элемент с прогрессом.

-   Ошибочные генерации явно видны в списке.
