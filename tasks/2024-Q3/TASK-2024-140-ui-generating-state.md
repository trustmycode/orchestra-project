## Описание

Компонент `DataSetListView.tsx` должен уметь отображать датасеты в процессе генерации и автоматически обновлять их статус.

## Техническое решение

1.  **Рендеринг в таблице (`DataSetListView.tsx`):**
    *   При рендеринге строки проверять `dataSet.status`.
    *   Если `status === 'GENERATING'`, отображать специальный индикатор:
        *   В колонке "Status" (если ее нет, добавить) показать `StatusBadge` с текстом "Generating..." и анимированным спиннером.
        *   Сделать строку некликабельной или задизейблить кнопки "Edit/Delete".
    *   Если `status === 'FAILED'`, отображать бейдж с ошибкой.

2.  **Механизм поллинга:**
    *   Реализовать `useEffect`, который запускает `setInterval` для вызова `getTestDataSets()` каждые 3-5 секунд.
    *   **Условие запуска:** Интервал должен запускаться только если в текущем списке `dataSets` есть хотя бы один элемент со статусом `GENERATING`.
    *   **Условие остановки:** Когда в обновленном списке не остается элементов со статусом `GENERATING`, `clearInterval` должен остановить поллинг.

## Критерии приемки

- [ ] В таблице появляется строка со статусом "Generating..." сразу после запуска генерации.
- [ ] UI автоматически обновляется, когда статус меняется на "Ready" или "Failed".
- [ ] Сетевые запросы (поллинг) прекращаются после завершения всех генераций.
