## Описание

Пользователь должен узнать о результате генерации, даже если он ушел со страницы списка сьютов.

## Ключевые шаги

1.  Создать контекст/хук `JobPoller`, который хранит список активных `jobId` (например, в LocalStorage или Memory).

2.  При старте генерации (из Wizard) добавлять ID в этот список.

3.  Периодически опрашивать статус активных задач.

4.  При переходе в `COMPLETED`:

    *   Показывать зеленый Toast: "Suite 'Order Process' generated successfully".

    *   Удалять ID из списка.

5.  При переходе в `FAILED`:

    *   Показывать красный Toast: "Generation failed: [Error Details]".

    *   Удалять ID из списка.

## Критерии приемки

-   Уведомление появляется поверх любого экрана приложения по завершении задачи.
