## Описание

Реализовать механизм сопоставления BPMN-задач с API-эндпоинтами из `ProtocolSpec`. Механизм должен быть гибридным: сначала точный поиск, затем эвристический/AI поиск.

## Ключевые шаги

1. Создать компонент `EndpointMatcher`.

2. **Стратегия 1 (Exact Match):** Поиск по совпадению `operationId` в метаданных BPMN-задачи и OpenAPI спецификации.

3. **Стратегия 2 (AI Fallback):** Если точное совпадение не найдено, вызвать `Mapping Agent` (см. `TASK-2024-039`).

   - Передать агенту имя задачи (Task Name) и список доступных эндпоинтов.

   - Получить наиболее вероятный кандидат.

4. Если маппинг найден (точно или через AI), сохранить связь в `ScenarioStep.endpointRef`.

## Критерии приемки

- Генератор успешно находит эндпоинт по `operationId`.

- Если `operationId` отсутствует, система пытается найти эндпоинт по семантическому сходству имени задачи (например, "Create Order" -> `POST /orders`).

- Если сопоставление не найдено, задача помечается как требующая ручной настройки (или создается placeholder-шаг).
