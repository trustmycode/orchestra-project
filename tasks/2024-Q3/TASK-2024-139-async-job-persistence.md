## Описание

Асинхронный воркер, выполняющий генерацию данных, должен по завершении обновить соответствующую placeholder-сущность `TestDataSet`.

## Техническое решение

1.  **Модификация `@Async` метода:**
    *   Метод теперь должен принимать `dataSetId` в качестве аргумента.

2.  **Логика по завершении генерации:**
    *   **При успехе:**
        1.  Найти `TestDataSet` по `dataSetId`.
        2.  Заполнить его поле `data` сгенерированным JSON.
        3.  Изменить `status` на `READY`.
        4.  Сохранить сущность.
    *   **При ошибке:**
        1.  Найти `TestDataSet` по `dataSetId`.
        2.  Изменить `status` на `FAILED`.
        3.  (Опционально) Сохранить текст ошибки в поле `description`.
        4.  Сохранить сущность.

## Критерии приемки

- [ ] После успешного завершения фоновой задачи, `TestDataSet` в базе данных обновляется: `status` становится `READY`, а поле `data` содержит JSON.
- [ ] В случае сбоя генерации, `status` меняется на `FAILED`.
